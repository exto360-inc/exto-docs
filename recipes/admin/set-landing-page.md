# How do I set where someone lands after signing in?

::: tip Who can do this
<Perm role="PME" /> — the application role that opens **Settings**.
:::

One menu item can be flagged as the **landing page** — where people arrive after
signing in.

## Steps

1. Open **Settings → Menu setup**.
2. Open the item that should be the landing page.
3. Flag it as the landing page.
4. Save and **activate** the menu.

## Result

People arrive there instead of the default. A dashboard works as a landing page
— it opens in a side panel the way the sidebar opens it.

If no landing page is set, people land on **Projects**.

::: tip Someone landing on Projects unexpectedly
That is usually a slow response rather than a missing setting. If the landing
page cannot be read within a few seconds, people are sent to Projects rather
than left on a spinner.
:::

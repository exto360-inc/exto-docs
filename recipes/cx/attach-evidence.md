# How do I attach evidence so it reaches the handover pack?

::: tip Who can do this
**Edit** on the stage.
:::

The handover package is compiled from an asset's evidence. A file attached to
the wrong thing is a file that does not appear in the pack — and nobody notices
until the pack is generated.

## Steps

1. Decide what the file is evidence **for**.
2. If it evidences a **checklist answer** — a photo of a reading, a signed
   certificate — attach it to **that item**, inside the cell.
3. If it describes the **asset itself** — a drawing, a datasheet — attach it to
   the asset's **Documents** tab.
4. Upload it and confirm it is listed.

## Result

The file appears against the thing it evidences, in the workbench's
**Documents** section, and in the handover package for that asset.

::: warning Convenient is not the same as correct
A photograph dropped on the asset when the checklist item asked for it satisfies
nobody: the item stays incomplete, and the handover pack has a gap where the
evidence should be.
:::

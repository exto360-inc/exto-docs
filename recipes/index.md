# Recipes

Whole tasks, start to finish, cutting across the lanes. Each one assumes you

## How these differ from the lane pages

A lane page describes a screen. A recipe crosses four of them in the order you
actually need, and says which decisions matter and which do not.

If you find yourself repeating a sequence that is not here, it probably
deserves to be.

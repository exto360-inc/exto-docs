# How do I request a revision?

::: tip Who can do this
A **Revision owner**, set per deployment in module setup — and only where the
module enables revision.
:::

A revision creates a **new version** of a completed record, keeping the original
intact. Use it when the record is a document of record — a signed inspection, an
issued order — and the history matters as much as the correction.

## Steps

1. Open the completed record.
2. Open the **Actions** widget.
3. Press **Revision**.
4. Enter a reason.

## Result

A new revision starts, and the previous one is preserved. Both remain
retrievable, so the change is visible rather than silent.

::: tip Revision or reopen?
**Reopen** puts the same record back in play — use it when the record was simply
not finished. **Revision** supersedes it with a new version — use it when the
original has to survive as evidence of what was signed at the time.
:::

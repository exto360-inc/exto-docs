# How do I attach a file or photo to a record?

::: tip Who can do this
Anyone who can edit the record.
:::

Files attached to a record are ordinary Exto documents — the same file appears
in [Drive](/work/documents), and images also appear in
[Photos](/work/photos). There is only one of it.

## Steps

1. Open the record.
2. Open the **Attachments** widget.
3. Choose **Upload**, from your device or from Google Drive.
4. Wait for it to finish, then check it is listed.

## Result

The file is attached, with version history and metadata. The record's row in the
[record list](/work/record-list) shows an attachment count, and clicking that
icon opens the files without opening the record.

::: warning Attach evidence where it is asked for
If a **checklist item** asks for an attachment, put it on that item — not on the
record generally. The item stays incomplete otherwise, and in a
[commissioning project](/cx/documents) the file will not reach the handover
pack.
:::

Replacing a file creates a **new version** rather than overwriting it, so the
earlier one stays retrievable.

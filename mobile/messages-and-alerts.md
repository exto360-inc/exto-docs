# Messages and alerts

The app shows short messages at the bottom of the screen (green for success, red
for problems) and banners at the top of some screens. The app does not send push
notifications; check **Tasks** for new work.

| Message | Where | Meaning |
|----|----|----|
| Offline — only downloaded modules are shown. | Menu | You are offline; only downloaded items are listed. |
| Offline — only downloaded records are shown. | Tasks | You are offline; only downloaded tasks are listed. |
| You're offline. Some actions are unavailable. / You're offline — reconnect to chat | Exto AI | Chat needs a connection. |
| You're offline — showing cached assets. / … showing downloaded stages only. | Commissioning | You are offline; you see what was downloaded. |
| You're offline — This module isn't available offline. Reconnect to view records. | Records list | The module was not downloaded. |
| Saved as offline draft | Forms | Your change is stored on the phone and will sync later. |
| Pending sync / Draft (offline) / (unsynced record) | Task, stage or record cards | The item has offline changes not yet synced. |
| Syncing {n} of {total} → Synced | Top of screen | Offline changes are being sent / have been sent. |
| Module downloaded successfully | Records list | The module is available offline. |
| The parent module "…" isn't offline yet — we'll download it along with this … | Download sheets | The module will be downloaded together with the task or stage. |
| {n} file(s) uploaded successfully / failed to upload | Drive | Result of an upload. |
| Downloading {name}… {n}% → Download successful / Download failed | Drive, Commissioning documents | File download progress and result. |
| Saved successfully | Checklists | A template was saved, submitted or approved. |
| ID and Name are required / Please add at least one item / All items must have a description | Checklists | Fix the template before saving. |
| No results found | Menu | Nothing matches your search. |
| All caught up! | Tasks | Nothing is assigned to you. |
| Display preferences saved / Profile picture updated / Offline data cleared | Profile | The setting was changed. |

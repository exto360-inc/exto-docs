# Dashboards and custom pages

Dashboards and custom pages are reports and pages built on the Exto web platform
and shown inside the app. Use them to review figures and lists for a tenant,
workspace or project without leaving the app.

Open them from the **Dashboards** or **Custom Pages** folder in **Menu**. Both
need an internet connection and are hidden from Menu when you are offline.

## Open a dashboard and choose a context

Each dashboard or page shows data for one context. The header shows the context
pill, the dashboard's name and, below it, the selected context.

1. In **Menu**, expand **Dashboards** (or **Custom Pages**) and tap the item.
2. If only one context applies, it is chosen for you and the content loads.
    Otherwise, tap the context pill at the top (it reads **Select Context** if
    none is chosen).
3. In the list, tap the context you want. Contexts that do not apply to this
    dashboard are greyed out; the selected one is ticked. Use **Search context**
    to find one.
4. The content reloads for that context.

The app remembers your last choice for each dashboard and page.

## Read a dashboard

Dashboards open at desktop width, so the content first appears very small.

1. Pinch outwards to zoom in, and pinch inwards to zoom out.
2. Drag to move around the page.

## Read a custom page

Custom pages open at phone width, so they are usually readable straight away.
Pinch to zoom where the page allows it.

## What you can do inside the content

- Everything below the header (tables, filters, **Save View** / **Reset View**
  and similar controls) is part of the web page and works as it does on the web.
- Links to records open the record in the app's own record form (see [Open and
  act on an existing
  record](/mobile/modules-and-records#open-and-act-on-an-existing-record)).
- Files you download from a dashboard or page are saved to your phone's
  Downloads folder, with a message such as "File downloaded" or "Download
  failed".

# Menu

The **Menu** tab ("Browse your modules") is where you open everything you have
access to: modules, master modules, dashboards, custom pages, commissioning
workbenches, Drive and, for PME users, Checklists. The items, their names and
their folders are set up by your organisation on the web, so different users can
see different menus.

## Open an item

1. Open the **Menu** tab.
2. Items are shown in two ways:
    - **Folders** (for example Dashboards, Custom Pages, Modules) show a count
      such as "3 modules" and a ▾ arrow. Tap a folder to expand it; its items
      appear inside it. Only one folder is open at a time, so opening another
      closes the first.
    - **Single items** (for example Drive or a master module) show a › arrow and
      open directly.
3. Tap the item you want.

Each item has a coloured badge with the first two letters of its name. Master
modules use a layers icon and Checklists a checklist icon.

## Search the Menu

1. Type in **Search modules...**.
2. Folders that contain a match expand automatically and show "{n} found".
3. If nothing matches, the Menu shows **No results found** — "No modules match
    '\<your text\>'".

## What each item opens

| Item type | Opens | See |
|----|----|----|
| Module | The records list for that module | Section [Modules and records](/mobile/modules-and-records) |
| Master module (layers icon) | The master records list | Section [Master modules](/mobile/master-modules) |
| Dashboard | A dashboard for a chosen context | Section [Dashboards and custom pages](/mobile/dashboards-and-custom-pages) |
| Custom page | A web page for a chosen context | Section [Dashboards and custom pages](/mobile/dashboards-and-custom-pages) |
| Drive | Files and folders | Section [Drive](/mobile/drive) |
| Checklists (PME only) | Checklist templates | Section [Checklists (PME users)](/mobile/checklists) |
| Commissioning workbench | The asset list | Section [Commissioning (CX)](/mobile/commissioning) |

## Menu while offline

When you are offline, a banner shows "Offline — only downloaded modules are
shown." Only downloaded modules, and commissioning workbenches with at least one
downloaded stage, remain; folder counts change to match. Dashboards, custom
pages, Drive and master modules are not available offline, and Checklists is
greyed out.

## Notes

- A PME user may see both **Checklists** (the template builder) and a module
  with a similar name, such as "Checklist Module". Checklists is where templates
  are built; the module holds ordinary records.

# Troubleshooting and FAQ

## Troubleshooting

| Problem | What to check |
|----|----|
| A module, dashboard or Drive is missing from Menu | If you are offline, only downloaded items are shown; reconnect. Otherwise your access is set on the web; contact your administrator. |
| Checklists is missing from Menu | Checklists is available only to PME users, and is greyed out offline. |
| There is no **+** button in a module | You do not have permission to create records in that module. |
| Exto AI or AI Insight is not available | Both need an internet connection. |
| A dashboard's text is very small | Dashboards open at desktop width. Pinch to zoom in. |
| A context in the list cannot be selected | It is greyed out because it does not apply or you do not have access to it. Choose another. |
| A commissioning level shows a lock | It has no stages, or (offline) none of its stages were downloaded. |
| The Upload button in Drive is disabled | Choose a context and at least one file. |
| Create is disabled when making a Drive folder | Fill in the context, the folder name and a document number pattern that contains {SEQ}. |
| **Clear all** is disabled when clearing offline data | Type CLEAR exactly as shown. |
| My offline record does not appear after reconnecting | Wait for the **Synced** pill; the list may briefly show 0 records while syncing. |
| Capture or Browse fails when creating a checklist | These options are currently unavailable. Use **Excel** or add items manually. |
| Some text stays in English after changing language | Some texts are not yet translated. |

### More checks

| Problem | What to check |
|----|----|
| A module shows "This module isn't available offline" | It was not downloaded. Reconnect, then download it from the records list ([Download a module for offline use](/mobile/modules-and-records#download-a-module-for-offline-use)). |
| A task or stage download also downloads its module | This is expected: the module is needed to open the task or stage offline. |
| Drive items are not in date order on the Recent tab | Drive currently lists items A–Z (see [Drive](/mobile/drive) notes). |
| Rows disappeared after an Excel import | Excel import replaces all rows in the Items table with the rows from the file. Check that the file uses the Exto checklist format. |

## Frequently asked questions

**What is the difference between Tasks and a module's records list?** Tasks
shows only records assigned to you, across all modules. A module's records list
shows all records in that module that you can see.

**Where do I change my name or password?** In Console. Go to **Profile**
› **Open Console**.

**How do I switch to another tenant?** Go to **Profile** and tap the card under
**Tenant** (the tenant switcher), then choose a tenant.

**Does logging out delete my offline work?** No. Offline data stays on the
phone. Sign in again to sync it.

**How do I remove everything downloaded to my phone?** **Profile** › **Offline
storage** › **Clear all offline data**, then type CLEAR.

**Can I preview a file in Drive?** Not in the app. Download it; it opens in your
phone's viewer.

**Which languages are available?** English, Hindi, Tamil and French.

**Why can't I edit a record?** Completed records are read-only, and your
workflow step may not allow editing. Master records you are not allowed to edit
also open read-only.

**What does PME mean?** PME users are responsible for monitoring and reporting
on project execution. They also have access to Checklists.

**How do I know what is available offline?** Downloaded items show a filled
cloud with a tick, and **Profile** › **Offline storage** lists every downloaded
module, task and stage.

**I picked Approve from the ▾ list, but nothing happened. Why?** Picking an
action from the list only changes the button. Tap the main button to carry out
the action.

**Can I attach files to an Exto AI question?** Yes, up to 3 files of up to 10 MB
each, from Drive or from your phone ([Attach
files](/mobile/exto-ai#attach-files)).

**Who can build checklist templates?** Only PME users, from **Menu** ›
**Checklists**.

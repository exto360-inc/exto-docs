# Tasks

The **Tasks** tab is your to-do list. It shows the records from all modules that
are assigned to you and waiting for your action. Start here each day to see what
needs your attention.

Open it from the **Tasks** tab (the second tab). The header shows how many
records are assigned to you, for example "77 records assigned to me".

## Find a task

**Search:** type part of a record number in **Search tasks**. The list updates
as you type; tap ✕ to clear the search.

### Filter:

1. Tap the funnel icon at the top right.
2. On the **Module** tab, tick the modules you want to see. On the **Context**
    tab, tick the contexts (for example a project). Use the **Search…** box to
    find an option.
3. Tap **Apply**. The funnel icon is highlighted while a filter is active.
4. To remove the filter, open it again and tap **Clear**.

<Shot src="mobile/task-filter" alt="The Filter sheet on the Context tab, with one context ticked."
  caption="The Filter sheet on the Context tab, with one context ticked." />

### Sort:

1. Tap the arrows icon at the top right.
2. Choose **Newest first**, **Oldest first**, **Record Number (A–Z)**, **Record
    Number (Z–A)**, **Context (A–Z)** or **Context (Z–A)**. The current choice
    is ticked.

<Shot src="mobile/task-sort" alt="The Sort by sheet. Newest first is the current choice."
  caption="The Sort by sheet. Newest first is the current choice." />

## Work on a task

1. Tap a task card. The record opens in the record form (see [Open and act on
    an existing
    record](/mobile/modules-and-records#open-and-act-on-an-existing-record)).
2. Review the details and fill in any fields your step requires.
3. Tap the workflow action at the bottom, for example **Submit**, **Approve**
    or **Return**.
4. When the action is complete, the record moves on in its workflow and, if it
    is no longer assigned to you, leaves your Tasks list.

When nothing is assigned to you, the list shows **All caught up!** — "No tasks
assigned to you at the moment."

## Download a task for offline use

Download a task before going somewhere without a connection, so you can still
open it and work on it.

1. Tap the cloud icon on the task card.
2. A sheet opens: **Download "\<task\>" for offline use** — "Changes made
    offline will sync automatically when you're back online." If the task's
    module is not yet downloaded, the sheet adds that the module will be
    downloaded along with the task.
3. Tap **Download**.
4. When the download is complete, the cloud icon on the card changes to a
    filled cloud with a tick.

<Shot src="mobile/task-download" alt="The download sheet for a task. The orange note says its module will be downloaded too."
  caption="The download sheet for a task. The orange note says its module will be downloaded too." />

## Tasks while offline

- A banner shows "Offline — only downloaded records are shown." Only downloaded
  tasks appear in the list.
- Open a downloaded task and act on it as usual. The app shows "Saved as offline
  draft" and the card shows **Pending sync**.
- When you are back online, the changes sync automatically. A pill at the top
  shows the progress, for example **Syncing 1 of 1** (see
  [Syncing](/mobile/working-offline#syncing)).

<Shot src="mobile/task-pending" alt="A downloaded task edited offline. The card shows Pending sync and the message confirms Saved as offline draft."
  caption="A downloaded task edited offline. The card shows Pending sync and the message confirms Saved as offline draft." />

## Notes

- The time on each card (for example "20h ago") is based on when the record was
  created, while **Newest first** sorts by submission date.

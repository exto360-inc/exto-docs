# Working in Exto

This lane is for using Exto rather than building it: finding the work that is
yours, filling in forms, moving records on, and finding what happened later.

## Start with your work

[My tasks](/work/my-tasks) is the answer to "what should I be doing" — every
record sitting on a step you are responsible for, in one grid.

## Two things worth knowing first

::: tip Save is not Submit
**Save** keeps a record exactly where it is, as a draft. Only an **action** —
Submit, Approve, Return — moves it to the next step and notifies anyone. A
record a colleague cannot find is usually a draft.
:::

::: tip You may not see every record
Without the **View all records** grant, you see the records your workflow step
makes yours. That is normally correct — it is not a fault. See
[Permissions](/concepts/permissions) if a record seems to be missing.
:::
